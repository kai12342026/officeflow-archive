## מה זה היה?

אפליקציית ווב שמחליפה את קובץ האקסל שבו רואת חשבון עצמאית מנהלת את הגבייה מהלקוחות שלה.

הפער בשוק הישראלי הוא לא עוד תוכנת חשבוניות, כי מורנינג, iCount, רווחית וסאמיט תופסות את זה. הפער הוא **כלי לרואה החשבון עצמו**: לוח בקרה אחד שמרכז את כל תיקי הלקוחות, מי שילם, מי בפיגור, ומאיזה לקוח עוד חסרים מסמכים כדי לסגור את הדיווח.

**מצב אז: דמו להצגה.** הנתונים באפליקציה מומצאים לחלוטין ויושבים בקוד, לא בבסיס נתונים. באנר קבוע בכל מסך אומר את זה במפורש.

### מה היה בדמו

| מסך | מה יש בו |

מה שמופיע בתפריט עם התג "בקרוב", קליטת מסמכים, הפקת דוחות, אנליטיקה והגדרות, הוא מפת הדרכים ולא חוסר. הוצא מההיקף במכוון כדי שהדמו יהיה עמוק ולא רחב.

## איך להריץ אותו?

### דרישות מקדימות
- Node.js 22+
- קובץ `.env.local` עם מפתחות Supabase (ראה סעיף Environment Variables)

### הרצה

```bash
npm install
npm run dev
```

ואז לפתוח `http://localhost:3000`.

### כניסה למערכת

הדשבורד מוגן מאחורי לוגין של Supabase. פרטי משתמש הדמו אינם במאגר.
ליצירת משתמש: Supabase Dashboard ← Authentication ← Users ← Add user.

יש כפתור **"אפס הדגמה"** בתחתית הסייד-בר, שמחזיר את נתוני הדמו למצב ההתחלתי.

---

## Stack

- **Next.js 16** (App Router, Turbopack) + **React 19**
- **Tailwind v4** (CSS-first — אין `tailwind.config`, הכול ב-`app/globals.css`)
- **shadcn/ui** בגרסת **Base UI** — שים לב: הרכבה נעשית עם `render={<El />}` ולא `asChild`
- **Supabase** (`@supabase/ssr`) — לאימות בלבד בשלב הזה
- **Recharts 3** דרך `components/ui/chart.tsx`
- **Vercel AI Gateway** (`ai` v7) למחולל ההודעות

## מה למדתי בתהליך?

**עברית לא מגיעה בחינם עם `dir="rtl"`.** הפונט שהיה בפרויקט הוא Inter, ול-Inter אין subset עברי בכלל. כלומר כל טקסט עברי נפל לפונט ברירת המחדל של מערכת ההפעלה — נראה שונה אצלי ואצל הלקוחה, ומרגיש לא מוגמר. ההחלפה ל-Heebo היא שורה אחת והיא השינוי הכי משמעותי ויזואלית שנעשה כאן.

**ב-Base UI צריך גם CSS וגם JS.** `dir="rtl"` על ה-`<html>` מטפל בכל ה-CSS — התכונות הלוגיות, הווריאנט `rtl:`, כיוון הטקסט. אבל `DirectionProvider` הוא זה שמטפל בניווט מקלדת ובמיקום פופאפים שמחושב ב-JS. ברירת המחדל שלו היא `ltr`, אז חייבים להעביר `direction="rtl"` במפורש. בלעדיו החצים בתפריטים הפוכים והפופאפים נפתחים לצד הלא נכון.

**Recharts לא באמת תומך ב-RTL, וזה בסדר.** הוא פולט `text-anchor="start|end"` ב-SVG, שמתהפכים תחת `dir="rtl"` ותולשים את כל תוויות ציר ה-Y מהציר. הפתרון הוא לא להילחם בזה אלא לנעול את הגרף ל-`dir="ltr"` ולשקף אותו הצהרתית: `<XAxis reversed />` ו-`<YAxis orientation="right" />`. תוויות בעברית טהורה מתרנדרות נכון גם בתוך מיכל LTR — רק כדאי להימנע מתוויות מעורבות כמו `"ינואר (2026):"`.

**טוקני צבע אפורים הורגים גרפים בשקט.** התבנית הגיעה עם `--chart-1..5` בגווני אפור טהור, ובנוסף עם ערכים **זהים** ב-light וב-dark. שום דבר לא נשבר — הגרפים פשוט יוצאים כמעט בלתי קריאים. שווה לבדוק את זה לפני שבונים גרף ראשון, לא אחרי.

**לפיצ'ר AI חי בדמו חייבת להיות נפילה.** ה-AI Gateway חזר עם שגיאת אמצעי תשלום דווקא בבדיקה האחרונה. בגלל שהראוט נופל לתבנית עברית דטרמיניסטית אחרי כשל או 6 שניות, הדמו נשאר מוצג לגמרי — ההודעה שיוצאת מהתבנית תקינה ומקצועית. חמש שורות קוד שהצילו את הפגישה.

**התשתית של Supabase הגיעה עם שני באגים שקטים.** הפניית `redirect` זרקה טוקנים שרוענו זה עתה (סשן שמת מוקדם בלי סיבה נראית), ו-`setAll` התעלם מארגומנט ה-headers שנושא `Cache-Control: no-store` — מה שמאפשר ל-CDN להגיש סשן של משתמש אחד למשתמש אחר. שניהם התגלו רק כשקראנו את הטיפוסים של הספרייה במקום להעתיק את הדוגמה הרשמית.
